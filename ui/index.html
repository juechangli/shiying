FROM DESKTOP TO POCKET

连接手机

电脑负责下载，手机负责把喜欢的视频带走。

在同一个 Wi-Fi 下使用

开启后，Android 或 iPhone 浏览器可以连接这台电脑。手机输入配对码后，只能查看自己提交的任务。

1. 保持电脑与此应用开启2. 手机扫码或输入连接地址3. 输入配对码，下载完成后保存到手机

这是当前 Wi-Fi 内的 HTTP 连接，请仅在可信网络使用。关闭连接会立即撤销手机访问。

✧

iPhone 可在 Safari 分享菜单中选择「添加到主屏幕」；Android 可使用浏览器的安装或添加快捷方式功能。保存视频时，文件位置由手机浏览器选择。
