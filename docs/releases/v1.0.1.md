# 拾影第一代 · VideoDock v1.0.1

> 历史发布记录：该版 Mac 包所含 FFmpeg 已确认启用 nonfree，不应继续分发。此文不是当前安装推荐；见 THIRD_PARTY_NOTICES.md。

第一代公开发布基线，包含 Windows x64 安装器和 Apple Silicon Mac 应用。
对应源码提交：de31f994a8bc495347fbd0bfe4b6d8989bb6132b。

## 已包含

- 桌面图形界面：粘贴网址、选择画质与目录、下载队列、进度、取消、重试、历史记录和打开文件。
- 内置 yt-dlp 与 FFmpeg，无需另外安装 Python。
- Android / iPhone 可在同一可信 Wi-Fi 中配对使用手机网页端，下载完成后保存文件。
- 1.0.1 修复粘贴链接拼接、进度输出遗漏与错误提示不明显；完成项显示 100%。
- 源码包含独立 Python 下载脚本。

## 下载选择

- Windows：VideoDock-1.0.1-Windows-x64-Setup.exe。
- Mac M 系列：VideoDock-1.0.1-macOS-AppleSilicon.zip，解压后将应用移至应用程序目录。
- 源码：VideoDock-1.0.1-Source.zip。
- SHA256SUMS.txt 用于核对上述文件。

## 已知边界

- 账号授权与登录后下载尚未实现；通用设计文档属于后续规划，不包含在本版功能中。
