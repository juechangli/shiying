# VideoDock 拾影 1.1.1

由 godlin 提供。自有内容按非商业使用许可提供；第三方组件保留自身许可。

提供 Mac Apple Silicon ZIP 和 Windows x64 NSIS 安装器。包含下载、进度、目录选择、历史及手机局域网配对；独立 X 身份授权需 Client ID，不用于下载授权受限视频。

FFmpeg 从官方签名通过的 9.0.2 原始源码自行编译，禁用 GPL/nonfree。Electron 更新为 44.4.5；修复 http-cache-semantics 构建依赖高危公告。构建链仍有 8 个中危关联条目。手机服务限可信网络及用户，原审计的其余边界仍适用。

安装包未进行商业签名或 Apple 公证。Windows 为交叉构建，未做真机安装测试。Mac 本轮验证覆盖下载/合并引擎及自动接口测试，不等于所有 GUI 和真实 X 授权验收。

组件源码和 SHA256SUMS 随 Release 提供。公开版不含签名读取脚本、用户数据或私人配置。
